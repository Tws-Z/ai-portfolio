# W10 预习：Function Calling、MCP 与普通 API

## 三句话辨析

1. **Function Calling（模型侧机制）**：模型根据用户问题输出“要调用哪个函数、参数是什么”的结构化请求，模型本身不执行函数，实际执行由应用程序完成。
2. **MCP（工具侧协议）**：一种让模型/客户端发现和调用外部工具、数据源的统一协议，重点解决“工具如何被标准化地提供出来”。
3. **普通 API 调用**：程序直接请求一个确定的 API 端点，调用哪个接口由程序员写死，模型不参与工具选择。

## 希望 MCP 接上的两个外部工具

### 1. 生词与 HSK 等级查询服务

- 工具名：`hsk_vocab_lookup`
- 输入：
  - `word`：中文词语或短语。
- 输出：
  - `word`
  - `hsk_level`
  - `part_of_speech`
  - `definition`
  - `source`
- 用途：让助手查确定性的词表和等级，而不是让模型凭记忆编造。

### 2. 学生成绩计算服务（本地/私有）

- 工具名：`score_calculator`
- 输入：
  - `scores`：成绩数组，例如 `[80, 90, 85]`
  - `weights`：可选权重数组，例如 `[0.3, 0.3, 0.4]`
- 输出：
  - `total`
  - `average`
  - `weighted_average`
  - `count`
- 用途：计算练习成绩或课程总评；学生成绩属于敏感数据，工具应在本地或受控私有环境中运行。
