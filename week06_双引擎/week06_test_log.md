## 4. 结果分析

### 本地正常时

本地引擎能返回答案，说明 Ollama HTTP 接口、模型名、超时和返回类型都正确。但同一个问题由 0.5b 生成的题目不完整，并且出现内容错误，说明“能跑通”不等于“质量合格”。

### 本地失败时

把本地地址改到未监听端口后，`LLM.ask(..., prefer="local")` 打印了真实的 `ConnectionError`，随后自动调用云端并返回完整答案。程序没有崩溃，也没有返回空字符串。

### 云端失败时

把云端域名改为无效地址后，`LLM.ask(..., prefer="api")` 打印了 `APIConnectionError`，随后自动回退本地并返回内容。双向回退成立，但本地回退答案仍需人工核验。

## 5. 课后作业 1：增强项说明

本次选择“打印调用耗时与费用估算”作为增强项：

- 本地引擎打印耗时、prompt/completion tokens 和 tok/s；
- 云端引擎打印耗时、token 数和按 `.env` 单价计算的费用；
- 没有在代码里硬编码会变化的 API 价格。

这样可以直接用同一条问题比较“本地是否够快、云端是否值得付费”。

## 6. 200 字反思：什么任务固定走本地，什么走云端

学生作文、成绩、评语和未公开教案属于隐私数据，应固定走本地，避免未成年人信息离开本机；断网课堂演示和格式固定、可人工校验的批量练习也优先本地。复杂教案设计、多步推理、长文改写和需要准确事实的 HSK 等级问题应走云端，因为 0.5b 在本机实测中会把 HSK4 词汇量和《愚公移山》内容答错。默认使用 `prefer="local"` 可以保证隐私，并让本地失败时自动回退云端；非敏感的高质量任务显式使用 `prefer="api"`。回退机制只保证程序不崩，不代表回退答案一定正确，所以所有教学内容仍需人工复核。

## 7. 作业 3：W7 RAG 预习

已准备学科文本：

```text
data/等级标准节选.txt
```

思考问题：模型再强，也可能不知道 HSK4 的具体数字，或者把旧版 HSK 与新标准混淆。RAG 的正确思路不是让模型“记住”数字，而是：

1. 从《国际中文教育中文水平等级标准》节选中检索出相关段落；
2. 把检索到的原文作为上下文交给模型；
3. 要求模型只依据给定资料回答，并附上资料来源；
4. 对没有检索到依据的问题明确说“资料中没有”，不能猜测。

这正好对应本次本地模型答错 HSK4 词汇量的实际问题。
