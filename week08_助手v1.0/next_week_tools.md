# W9 预习：希望助手拥有的两个工具

## 工具 1：查生词表

- 函数名：`lookup_vocabulary(word)`
- 输入：`word`，一个中文词语，例如 `商量`。
- 输出：JSON 或表格，包含：
  - HSK 等级
  - 词性
  - 释义
  - 数据来源（`data/生词表.csv`）
- 用途：让助手回答“商量是什么等级、什么词性”时不再凭记忆猜测。

## 工具 2：安全计算器

- 函数名：`safe_calculate(expression)`
- 输入：只包含数字、括号和四则运算符号的字符串，例如 `(80 + 90) / 2`。
- 输出：
  - 计算结果
  - 如果表达式非法或包含函数调用，返回“拒绝计算”及原因。
- 用途：计算平时成绩、作文分数平均值等，不能用 `eval()` 直接执行任意代码。

## 工具调用的输入输出原则

1. 工具必须返回结构化、可验证的结果。
2. 模型负责选择工具和解释结果，不能伪造工具返回。
3. 工具失败时返回明确错误，不返回空值。
4. 学生隐私数据只在本地工具和本地模型中使用。
