# W8 助手 v1.0 演示记录

## 测试环境

- 本地引擎：Ollama + qwen2.5:0.5b
- 云端引擎：DeepSeek OpenAI 兼容接口
- 知识库：`data/等级标准节选.txt`
- RAG：W7 `retrieve()` + `build_prompt()` + Chroma
- 统一模型入口：W6 `LLM.ask()`

## 结论

- RAG 开启的云端回答在 3 个核心问题上均为 3245、1200、424，能引用检索片段。
- 本地 0.5b 运行成功，但无论纯对话还是 RAG 都可能答错，适合隐私草稿和离线演示，不适合作为最终教学事实来源。
- 同一问题关闭 RAG 后，模型会回到凭参数记忆作答；即使偶尔正确，也没有来源可核验。
- 所有答案已保存在 `w8_answer_results.json`。
